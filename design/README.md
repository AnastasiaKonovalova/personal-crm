# Эскизы экранов по дизайн-системе

Эскизы — статичный HTML на токенах и `ak-`классах дизайн-системы (`ak-design-system/`, не в git). Они — эталон вида приложения: правка дизайна идёт сначала в эскизе, владелец её утверждает, потом она переносится в код. Как дизайн-система устроена в коде — `src/design-system/README.md`.

Эскиз правится за пару строк, код приложения при этом не трогается. Отклонены: Claude Design / canvas (дорогой перенос в код — эскиз не на токенах), сразу в Next.js (правки засоряют код до утверждения), публикация эскизов на claude.ai (владелец решил — только локально).

## Как смотреть

```bash
open design/index.html
```

`index.html` — обзор: каждый экран в 1280 (уменьшен вдвое) и 390. Заголовок экрана открывает его целиком. Скриншоты всех эскизов — `zsh scripts/mockup-shots.sh` (см. `AGENTS.md`).

Эскизы самодостаточны: стили дизайн-системы лежат копией в `vendor/`. Если дизайн-система поменяется — обновить копии. Подключение в каждом экране: `vendor/fonts.css` → `vendor/tokens.css` → `vendor/styles.css` → `app.css`, корень `<div class="ak-root">`.

## Решения

Статусы: **предложено** → **утверждено** / **отклонено**. Новое решение — новой строкой, статус обновлять по ходу.

| # | Решение | Почему | Статус |
|---|---|---|---|
| 1 | Главная кнопка — `ink` на `accent` (класс `ak-btn-primary`), а не белый на золоте (`ak-btn-solid`) | белый на золоте 1.8:1, нечитаемо; дизайн-система для новых важных кнопок советует `ink` на `accent` (5.1:1) | утверждено |
| 2 | Одна золотая кнопка на экран. «Сохранить» в правке заметки — ghost; «Изменить» и «Отмена» в заметках — текстовые | правило дизайн-системы: не больше одной solid-кнопки на вид | утверждено |
| 3 | Золотая подсветка (aurora) только на экранах списка; на карточке и формах нет | не отвлекает в рабочих экранах | утверждено |
| 4 | Страницы — круглые стрелки (паттерн карусели) + «Страница **1** из 20»; подписи «Назад»/«Вперёд» только в `aria-label` | паттерн из дизайн-системы | утверждено |
| 5 | Таблица → карточка-список; строка кликабельна целиком, ховер `teal-soft`; на 390 скрыта колонка «Откуда знакомы» | карточки и пилюли вместо таблиц — язык дизайн-системы | утверждено |
| 6 | Новые тексты: подсказка «Проверь написание…» на «никого не нашлось»; на редактировании ссылка назад — имя контакта | понятнее; легко убрать | утверждено |
| 7 | Шапка — только бренд «Личная CRM» с золотой точкой; без переключателя языка | приложение одноязычное | утверждено |
| 8 | Ошибки — токен `--danger` `#b93c1c` (тёплый красный, выбран владельцем; ~5:1 на `bg`): текст 600 + иконка Lucide `circle-alert`, рамка поля `--danger`, фон поля `--danger-soft` `#fbe9e3`. Поле → ошибка 8px во всех формах. Звёздочка обязательного поля — `brown`, это не ошибка | сначала ошибки были `brown` — не выделялись; перебрали `#c41e3a` → `#c4401e` (4.5:1, без запаса) → `#b93c1c`; токены есть в дизайн-системе с теми же значениями | утверждено |
| 9 | Метки полей в карточке — мелкие UPPERCASE (шрифт заголовков Wix Madefor Display, `muted`); в формах — Manrope 600 `ink` | иерархия по правилам типографики | утверждено |
| 10 | Поля сверены с `TextField` дизайн-системы: текст в поле 16px (без зума на iPhone) и рамка фокуса `danger` у поля с ошибкой; метка — наша (решение 9), текст ошибки 13px / 600. Высота поля в коде 52px (как кнопка), в эскизах 54px | владелец выбрал вариант 1 из трёх (2026-10-23) | утверждено |
| 11 | «Удалить» в карточке — текстовая кнопка с иконкой Lucide `trash-2` справа от «Редактировать» (ghost); не красная | дизайн-система запрещает `danger` на кнопках; удаление не главное действие | утверждено |
| 12 | Диалог подтверждения: `surface`, рамка `line`, `radius-contact`, подложка `header-glass` с blur 10px, ширина до 440px; крестик вверху справа; «Удалить» — главная (золотая), «Отмена» — ghost; при открытии фокус на «Отмена» | маппинг «Dialog» из `ak-design-system/CLAUDE.md`; золотая кнопка карточки под подложкой неактивна, золотая в диалоге одна; фокус на безопасном действии — Enter не удаляет случайно | утверждено |
| 13 | «Контакт удалён» — пилюля внизу по центру: `surface`, рамка `line`, бирюзовая точка, крестик 44px (`hit-carousel`), ховер крестика `teal-deep` на `teal-soft`; без тени | бирюза = «готово»; плоский стиль без новых теней; внизу не закрывает заголовок и «Всего» | утверждено |
| 14 | Блок «Пора связаться» — карточка между заголовком и поиском; строка кликабельна целиком (ховер `teal-soft`), «Связались» поверх; внизу текстовая кнопка «Показать все (N)» `teal-deep`; раскрытый блок - по 10 строк, внизу слева пагинация блока (круглые стрелки и «Страница X из Y», как решение 4, но кнопки), справа «Свернуть»; на ≤560 друг под другом. Переключение и листание на месте, без перезагрузки | тот же язык, что у списка; блок первым видно без прокрутки; владелец: «Свернуть» и «Показать все» - кнопки, не переход по ссылке; много просроченных - пагинация, не прокрутка внутри блока | утверждено |
| 15 | Точки: «просрочено» — новый токен `--overdue` `#d9622b` (терракота, 3,4:1), пульс 2 с; «скоро» — `teal`, пульс как у `StatusPill`. Под reduced motion пульс стоп. У строк без статуса пустой слот 8px — имена не скачут. Смысл — скрытый текст «пора связаться» / «скоро пора связаться» | владелец: «просрочено» с красным оттенком, «скоро» — бирюза с пульсом. Осознанно отступаем от правила «одна пульсирующая точка на страницу». Вариант A (`danger`) отклонён: путается с ошибками | утверждено |
| 16 | «Связались» — ghost, иконка «рукопожатие в галочке» (Lucide `handshake`: `translate(3.5 1.2) scale(.62)`, линия 2.3, лежит в развилке крупной галочки `M2 13.5l7 7.5L22.5 10`; 22px, `teal-deep`) и подпись; в строке блока на ≤560 только круглая иконка 44px с `aria-label` | не золотая (решение 2); иконку выбрала владелец вместо «телефона + галочки»: связь бывает не только по телефону; без сердечка — не путается с «Со всеми на связи»; положение рук и угол галочки поправила владелец | утверждено |

| 18 | В карточке — отдельная карточка «Связь» над данными: статус, «Связались», форма «Как часто связываться» с ghost «Сохранить» (работает без JS) | главное действие фичи видно сразу; золотая на экране остаётся одна — «Добавить заметку» | утверждено |
| 19 | Поле частоты — нативный `select` в виде пилюли с шевроном Lucide `chevron-down`; при «Конкретная дата» справа поле даты, ошибка под обоими | без JS и без новой библиотеки; ошибка как в решении 8 | утверждено |
