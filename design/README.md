## С чего начать следующую сессию

Остановились 2026-10-27 после **этапа 7** (просмотр в браузере, исправление фокуса, ручные проверки в корневом `README.md`). Следующий шаг — **этап 8: хвосты** (удалить неиспользуемые shadcn `Table`/`Card` — только с разрешения владельца; `src/design-system/README.md`; подчистить этот README).

Как смотреть в браузере (выяснено 2026-10-23, уточнено 2026-10-27): владелец запускает `pnpm dev` и подключает Claude in Chrome. Окно не растягивается шире 937px и `resize_window` его не сужает — ширину 390 смотреть через iframe 390px, вставленный в страницу через `javascript_tool` (как в `scripts/mockup-shots.sh`). Данные в базе не создавать: проверять ошибки пустыми формами; «Заметка сохранена» покрывает e2e. Команды расширению отправлять по одной, не пачкой, и держать открытой только свою вкладку с расширением: при параллельных вызовах (и, возможно, второй вкладке с расширением) действия падают с «Couldn't determine which page this action targets». Фокус с клавиатуры можно включать `el.focus({focusVisible: true})`; стиль читать через ~400ms — `transition-colors` анимирует и цвет рамки. План и статусы — в таблице «План переноса» ниже.

Как работаем (договорённости с владельцем):
- Поэтапно: этап → проверки → владелец смотрит → сообщение коммита на согласование → коммит. К следующему этапу — только после «ок»
- Постоянное «ок» владельца на набор проверок после каждого этапа: `pnpm typecheck`, `pnpm test` — агент запускает сам; база, `pnpm build`, `pnpm start` + `pnpm test:e2e` — песочница агента их не пускает (нет Docker, next/font не качает шрифты через прокси), поэтому владелец запускает `zsh scripts/checks.sh`, агент читает `tmp/checks.log`. Любые другие команды — согласовывать
- Перед `scripts/checks.sh` остановить `pnpm dev`: сборка и dev пишут в одну `.next`. Если `pnpm dev` пишет «Port 3000 is in use» — на 3000 висит старый сервер (стили там отдают 500); остановить его (`kill <pid>`)
- Скриншоты эскизов: владелец запускает `zsh scripts/mockup-shots.sh`, агент читает `tmp/shots/*.png`. Живое приложение (ховер, фокус, формы) — через расширение Claude in Chrome на этапе 7, его включает владелец
- Задачи вне переноса — в `specs/backlog.md` (скорость приложения, шрифты в репо, esbuild)
- Пуш и PR — только по просьбе владельца

## Зачем так

Эскизы — статичный HTML на токенах и `ak-`классах дизайн-системы. Правка стоит пару строк и обновление вкладки, код приложения не трогается. После утверждения разметка переносится на React-компоненты.

Рассмотрены и отклонены:
- Claude Design / canvas — правки удобные, но перенос в код дорогой: эскиз собран не на `ak-`классах и токенах
- сразу в Next.js (роут `/design`) — каждая правка идёт через React/Tailwind/shadcn, засоряет код до утверждения
- публикация эскизов как Artifact на claude.ai — владелец отказался, только локально

## Как смотреть

```bash
open design/index.html
```

`index.html` — обзор: каждый экран в 1280 (уменьшен вдвое) и 390. Заголовок экрана открывает его целиком.

Эскизы самодостаточны: стили дизайн-системы лежат копией в `design/vendor/` (`fonts.css`, `tokens.css`, `styles.css` из `ak-design-system/`). Если дизайн-система поменяется — обновить копии.
