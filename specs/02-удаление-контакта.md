# Удаление контакта

## Зачем

Убрать из CRM человека, который больше не нужен: контакт и все его заметки удаляются насовсем.

## Сценарий

1. Открыл карточку контакта → нажал «Удалить»
2. Появился диалог: «Удалить контакт? Заметки тоже удалятся» → «Удалить» / «Отмена»
3. Нажал «Удалить» в диалоге → контакт удалён, открылся список контактов, удалённого в нём нет
4. На списке появилось сообщение «Контакт удалён» с кнопкой закрытия; через 3 секунды оно исчезает само

Передумал: «Отмена», крестик или Esc → диалог закрылся, контакт на месте.

## Решения владельца

- Кнопка «Удалить» - только в карточке контакта, в форме редактирования её нет
- Перед удалением - свой диалог подтверждения «Удалить контакт? Заметки тоже удалятся» с кнопками «Удалить» и «Отмена» и крестиком закрытия вверху справа; сам не исчезает
- После удаления - переход на список
- Сообщение «Контакт удалён» - своё (не стандартное окно браузера), живёт 3 секунды, отсчёт не показывается; кнопка закрытия есть и доступна всё время, пока сообщение видно
- Удаление насовсем, без корзины и восстановления
- Сначала эскиз в `design/`, потом код

## Критерии приёмки

- В карточке есть кнопка «Удалить»; в форме редактирования её нет
- «Удалить» в карточке открывает диалог подтверждения, контакт пока не удалён
- «Отмена», крестик или Esc → диалог закрыт, контакт и заметки на месте
- Диалогом можно пользоваться с клавиатуры: фокус переходит в диалог, после закрытия возвращается на кнопку «Удалить»
- «Удалить» в диалоге → открылся список; контакта нет в списке и в поиске; «Всего» уменьшилось на 1
- Адрес карточки удалённого контакта отдаёт «не найдено»; заметок этого контакта в базе нет
- После удаления на списке видно «Контакт удалён»; через 3 секунды сообщение исчезает само
- Крестик закрывает сообщение сразу; он виден и нажимается всё время, пока сообщение на экране
- Обновил страницу списка или открыл его заново → сообщения нет
- Удалили контакт в другом браузере, а здесь нажали «Удалить» в диалоге → открылся список, ошибки нет
- Удаление видно в другом браузере: открыл список там → контакта нет

## Модель данных

Не меняется. Заметки привязаны к контакту с `onDelete: cascade`: база удаляет их вместе с контактом. Миграция не нужна.

## Не делать

Корзина, восстановление, отмена удаления, массовое удаление, удаление из списка или формы редактирования, отсчёт времени на сообщении.
