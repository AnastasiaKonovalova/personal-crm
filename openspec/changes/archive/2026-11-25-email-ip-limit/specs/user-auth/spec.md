# Spec Delta

## MODIFIED Requirements

### Requirement: Лимит писем
На одну почту MUST уходить не больше 3 писем за 10 минут. С одного IP MUST уходить не больше 10 писем за час, на любые почты, в том числе при запросе мимо формы. Сверх любого из лимитов письмо MUST NOT уходить, человек MUST видеть «Слишком часто, попробуй через несколько минут» вместо текста об отправке.

#### Scenario: Четвёртый запрос за 10 минут
- **WHEN** человек запросил ссылку для одной почты три раза и в те же 10 минут запрашивает в четвёртый
- **THEN** он видит «Слишком часто, попробуй через несколько минут», четвёртое письмо не уходит

#### Scenario: Лимит после пробелов и регистра
- **WHEN** три запроса были для `anna@example.com`, а четвёртый за те же 10 минут — для `ANNA@example.com `
- **THEN** он видит «Слишком часто, попробуй через несколько минут», письмо не уходит

#### Scenario: Лимит одной почты не мешает другой
- **WHEN** лимит для `anna@example.com` исчерпан, и человек запрашивает ссылку для `boris@example.com`
- **THEN** он видит «Ссылка для входа отправлена на boris@example.com», письмо приходит

#### Scenario: После 10 минут снова можно
- **WHEN** с первого из трёх запросов для почты прошло больше 10 минут
- **THEN** новый запрос даёт «Ссылка для входа отправлена на <почта>», письмо приходит

#### Scenario: 11-й запрос с одного IP за час
- **WHEN** с одного IP за час ушло 10 писем на 10 разных почт, и с него же запрашивают ссылку для 11-й почты
- **THEN** он видит «Слишком часто, попробуй через несколько минут», письмо на 11-ю почту не уходит

#### Scenario: Лимит одного IP не мешает другому
- **WHEN** лимит для одного IP исчерпан, и ссылку запрашивают с другого IP
- **THEN** он видит «Ссылка для входа отправлена на <почта>», письмо приходит

#### Scenario: После часа снова можно
- **WHEN** с первого из 10 писем с одного IP прошло больше часа
- **THEN** новый запрос с этого IP даёт «Ссылка для входа отправлена на <почта>», письмо приходит

#### Scenario: Лимит IP для запроса мимо формы
- **WHEN** лимит для IP исчерпан, и с него же приходит запрос ссылки на сервер напрямую, не из формы
- **THEN** запрос отклоняется, письмо не уходит
