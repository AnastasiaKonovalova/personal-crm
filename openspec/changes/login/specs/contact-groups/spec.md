# Spec Delta

## MODIFIED Requirements

### Requirement: Имя группы
Имя группы MUST быть обязательным; пробелы по краям обрезаются. Имя MUST быть уникальным среди групп одного пользователя без учёта регистра и без различия «е» и «ё»; у разных пользователей имена MAY совпадать. Длина имени MUST быть не больше 50 символов.

#### Scenario: Пустое имя
- **WHEN** владелец на странице «Группы» создаёт группу с именем из одних пробелов
- **THEN** группа не создаётся, у поля ошибка «Укажи название»

#### Scenario: Такое имя уже есть
- **WHEN** группа «Друзья» есть, и владелец на странице «Группы» создаёт группу «друзья»
- **THEN** группа не создаётся, у поля ошибка «Такая группа уже есть»

#### Scenario: «Ё» и «е» не различаются
- **WHEN** группа «Ёлка» есть, и владелец на странице «Группы» создаёт группу «Елка»
- **THEN** группа не создаётся, у поля ошибка «Такая группа уже есть»

#### Scenario: Слишком длинное имя
- **WHEN** владелец создаёт группу с именем длиной 51 символ
- **THEN** группа не создаётся, у поля ошибка «Не длиннее 50 символов»

#### Scenario: Такое имя у другого пользователя
- **WHEN** у пользователя A есть группа «Друзья», и пользователь B создаёт группу «друзья»
- **THEN** группа создаётся у B, ошибки нет

#### Scenario: «Новая группа» с именем чужой группы
- **WHEN** у A есть группа «Соседи», и B в форме контакта вводит в «Новая группа» имя «Соседи»
- **THEN** у B создаётся своя группа «Соседи», контакт B попадает в неё, группа A не меняется
