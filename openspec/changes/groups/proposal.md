# Proposal

## Why

Контакты сейчас лежат одним списком, отсортированным по имени. Когда людей сотни, нельзя быстро увидеть «всех из тенниса» или «всю семью». Нужны группы, которые владелец заводит сам и в которые раскладывает людей.

## What Changes

- Группы - именованные наборы контактов, которые владелец создаёт сам («Семья», «Друзья», «Теннис», «Аналитики»). Встроенных групп нет
- Контакт может состоять в нескольких группах сразу или ни в одной
- Группы контакта задаются в формах создания и редактирования (отметки и поле «Новая группа») и прямо в карточке: добавить, убрать (после подтверждения), создать новую. Без JavaScript тоже работает
- Страница «Группы»: список групп с числом контактов, создание, переименование, удаление с подтверждением. При удалении группы контакты остаются, теряется только членство
- Страница группы `/groups/<id>`: «Контакты в группе <название>», ссылки «Все группы» и «Все контакты», поиск по имени внутри группы, блок «Пора связаться» по группе, «Добавить контакт» с уже отмеченной группой; без переключателя и фильтра. Сюда ведут группа на странице «Группы» и плашка группы в карточке; удалённая группа - страница «Не найдено»
- Над блоком «Пора связаться» - переключатель «Контакты» / «Группы» между двумя страницами
- Имя группы обязательно, до 50 символов, уникально без учёта регистра и «е/ё»
- В строке общего списка - группы контакта: шире 1100px до трёх, 681–1100px до двух, 680px и уже одна, остальные - значком «+N»; наведение или тап по «+N» показывает всплывашку с остальными группами. Группы не сжимают и не перекрывают другие данные строки и не являются ссылками
- На главной фильтр по группе - выпадающий список отдельной строкой под поиском, с подписью «Фильтр по группам»; первый вариант «Все группы» - он же сброс. Работает вместе с поиском
- Блок «Пора связаться» с фильтром показывает только контакты группы
- Модель данных: две новые таблицы (группы и связь «контакт - группа»). Миграция только добавляет таблицы, существующие контакты остаются без групп

## Capabilities

### New Capabilities

- `contact-groups`: группы контактов - создание, переименование и удаление, членство контакта в нескольких группах, группы в формах, карточке и строке списка, фильтр по группе, страница «Группы» и переключатель к ней

### Modified Capabilities

- `keep-in-touch`: блок «Пора связаться» показывается и с фильтром по группе - только с контактами группы (требование «Блок „Пора связаться“»)

## Impact

- База: `src/db/schema.ts` - таблицы `groups` и `contact_groups`, миграция Drizzle
- Сервер: новый `src/server/groups.ts`; `src/server/contacts.ts` - группы контакта при создании и правке, в карточке и в списке, фильтр в `listContacts` и `listReminders`
- Действия: `src/app/contacts/actions.ts` - группы в формах и в карточке; новый `src/app/groups/actions.ts`
- Экраны: новые страницы `src/app/groups/page.tsx` и `src/app/groups/[id]/page.tsx`; главная (`src/app/page.tsx`) - переключатель, фильтр, группы в строке; список контактов - общий компонент главной и страницы группы; карточка; форма контакта (и `/contacts/new?group=<id>` с отмеченной группой)
- Дизайн: эскизы в `design/` утверждены, решения 21–30 в `design/README.md`
- Тесты: юнит-тесты валидации и раскладки групп в строке, интеграционные тесты на базе (Vitest). e2e и CI - позже (`specs/backlog.md`)
- Новых зависимостей нет: всплывашка - на встроенном в браузер `popover`
