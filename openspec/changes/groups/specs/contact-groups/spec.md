# Spec Delta

## Purpose

Позволяет раскладывать контакты по группам, которые владелец заводит сам, и быстро находить людей одной группы: семью, друзей, коллег по увлечению.

## ADDED Requirements

### Requirement: Группы создаёт владелец
Владелец MUST иметь возможность создать группу с любым именем: на странице «Группы», в форме создания контакта, в форме редактирования и в карточке контакта. Встроенных групп MUST NOT быть: в пустой базе групп нет.

#### Scenario: Создание на странице «Группы»
- **WHEN** владелец на странице «Группы» создаёт группу «Теннис»
- **THEN** группа «Теннис» появляется в списке групп с числом контактов 0

#### Scenario: Групп нет
- **WHEN** владелец открывает страницу «Группы», а групп ещё нет
- **THEN** страница показывает пустое состояние «Групп пока нет» и форму создания

### Requirement: Имя группы
Имя группы MUST быть обязательным; пробелы по краям обрезаются. Имя MUST быть уникальным без учёта регистра и без различия «е» и «ё». Длина имени MUST быть не больше 50 символов.

#### Scenario: Пустое имя
- **WHEN** владелец на странице «Группы» создаёт группу с именем из одних пробелов
- **THEN** группа не создаётся, у поля ошибка «Укажи название»

#### Scenario: Такое имя уже есть
- **WHEN** группа «Друзья» есть, и владелец на странице «Группы» создаёт группу «друзья»
- **THEN** группа не создаётся, у поля ошибка «Такая группа уже есть»

#### Scenario: «Ё» и «е» не различаются
- **WHEN** группа «Ёлка» есть, и владелец на странице «Группы» создаёт группу «Елка»
- **THEN** группа не создаётся, у поля ошибка «Такая группа уже есть»

#### Scenario: Слишком длинное имя
- **WHEN** владелец создаёт группу с именем длиной 51 символ
- **THEN** группа не создаётся, у поля ошибка «Не длиннее 50 символов»

### Requirement: Переименование группы
Владелец MUST иметь возможность переименовать группу на странице «Группы» по тем же правилам имени. Состав группы при переименовании MUST NOT меняться. Сохранение группы под её же именем, в том числе в другом регистре, MUST проходить.

#### Scenario: Новое имя
- **WHEN** владелец переименовывает «Теннис» в «Теннис по субботам»
- **THEN** у всех контактов группы в карточке видна группа «Теннис по субботам», состав группы тот же

#### Scenario: Смена регистра
- **WHEN** владелец переименовывает «теннис» в «Теннис»
- **THEN** ошибки нет, группа называется «Теннис»

### Requirement: Удаление группы
Удаление группы на странице «Группы» MUST требовать подтверждения. После удаления контакты группы MUST остаться со всеми данными, заметками и другими группами; исчезает только членство в удалённой группе.

#### Scenario: Удаление группы с контактами
- **WHEN** в группе «Аналитики» 3 контакта, и владелец удаляет группу и подтверждает
- **THEN** группы «Аналитики» нет, все 3 контакта на месте, их заметки и другие группы не изменились

#### Scenario: Отмена удаления
- **WHEN** владелец нажимает «Удалить» у группы и в подтверждении выбирает «Отмена»
- **THEN** группа и её состав не изменились

### Requirement: Контакт в нескольких группах
Контакт MUST иметь возможность состоять в любом числе групп, в том числе ни в одной. Существующие контакты после выкатки MUST быть без групп, их данные и заметки не меняются.

#### Scenario: Две группы сразу
- **WHEN** владелец отмечает у контакта группы «Друзья» и «Теннис»
- **THEN** контакт виден в фильтре по «Друзьям» и в фильтре по «Теннису»

#### Scenario: Существующие контакты после выкатки
- **WHEN** фича выкачена на базу с контактами
- **THEN** у всех существующих контактов нет групп, их данные, частота и заметки не изменились

### Requirement: Группы в формах контакта
В формах создания и редактирования контакта MUST быть отметки всех групп и поле «Новая группа». Новая группа MUST создаваться при сохранении контакта и сразу включать его. Отметки и поле MUST сохраняться вместе с контактом и работать без JavaScript.

#### Scenario: Группы при создании
- **WHEN** владелец создаёт контакт и отмечает «Семья»
- **THEN** в карточке нового контакта видна группа «Семья»

#### Scenario: Новая группа в форме
- **WHEN** владелец в форме редактирования пишет в «Новая группа» «Аналитики» и сохраняет
- **THEN** группа «Аналитики» создана, контакт в ней

#### Scenario: В «Новая группа» имя существующей
- **WHEN** группа «Друзья» есть, и владелец пишет в «Новая группа» «друзья» и сохраняет контакт
- **THEN** новая группа не создаётся, контакт добавлен в «Друзья», ошибки нет

#### Scenario: Снять группу при правке
- **WHEN** контакт в группах «Друзья» и «Теннис», и владелец в форме редактирования снимает «Теннис»
- **THEN** контакт остаётся только в «Друзьях»

#### Scenario: Ошибка формы не теряет группы
- **WHEN** владелец отмечает «Семья», пишет в «Новая группа» «Аналитики», стирает имя контакта и сохраняет
- **THEN** контакт не сохраняется, ошибка «Имя обязательно», группа «Аналитики» не создана, отметка «Семья» и текст «Аналитики» на месте

#### Scenario: Ошибка имени новой группы
- **WHEN** владелец пишет в «Новая группа» имя длиной 51 символ и сохраняет контакт
- **THEN** контакт не сохраняется, у поля «Новая группа» ошибка «Не длиннее 50 символов»

### Requirement: Группы в карточке
Карточка контакта MUST показывать его группы по алфавиту; каждая MUST вести на главную с фильтром по ней. В карточке, без перехода в форму, владелец MUST иметь возможность добавить контакт в существующую группу, убрать из группы и создать новую группу с этим контактом. Убрать из группы MUST только после подтверждения. Изменения и подтверждение MUST работать без JavaScript.

#### Scenario: Карточка с группами
- **WHEN** контакт в группах «Теннис» и «Друзья»
- **THEN** в карточке видно «Друзья», «Теннис» в этом порядке

#### Scenario: Переход к группе
- **WHEN** владелец в карточке нажимает на группу «Теннис»
- **THEN** открывается главная со списком контактов группы «Теннис»

#### Scenario: Добавить в группу из карточки
- **WHEN** владелец в карточке добавляет контакт в существующую группу «Семья»
- **THEN** карточка показывает «Семья» среди групп, остальные данные контакта не изменились

#### Scenario: Убрать из группы в карточке
- **WHEN** контакт в «Друзьях» и «Теннисе», владелец в карточке нажимает крестик у «Теннис» и подтверждает «Убрать»
- **THEN** в карточке только «Друзья», группа «Теннис» осталась на странице «Группы»

#### Scenario: Случайное нажатие крестика
- **WHEN** владелец нажимает крестик у группы «Теннис» и в подтверждении выбирает «Отмена»
- **THEN** контакт остаётся в «Теннисе», группы в карточке не изменились

#### Scenario: Имя существующей группы в карточке
- **WHEN** группа «Друзья» есть, и владелец в карточке пишет «друзья» и добавляет
- **THEN** новая группа не создаётся, контакт добавлен в «Друзья»

#### Scenario: Новая группа из карточки
- **WHEN** владелец в карточке создаёт группу «Соседи»
- **THEN** группа «Соседи» создана, контакт в ней, на странице «Группы» у неё 1 контакт

#### Scenario: Контакт без групп
- **WHEN** контакт не состоит ни в одной группе
- **THEN** в карточке вместо списка групп текст «Ни в одной группе» и возможность добавить

### Requirement: Группы в строке общего списка
Строка общего списка MUST показывать группы контакта по алфавиту: шире 1100px - до трёх, от 681 до 1100px - до двух, 680px и уже - одну; остальные - значком «+N», где N - число не показанных групп. Группы MUST занимать своё место в строке и MUST NOT наезжать на имя, «Кто это» и «Откуда знакомы» или сжимать их; длинное имя группы обрезается с многоточием.

#### Scenario: Широкий экран, пять групп
- **WHEN** у контакта 5 групп, экран широкий
- **THEN** в строке 3 первые по алфавиту группы и «+2»

#### Scenario: Средний экран, пять групп
- **WHEN** у контакта 5 групп, экран шириной 900
- **THEN** в строке 2 первые по алфавиту группы и «+3»

#### Scenario: Узкий экран, три группы
- **WHEN** у контакта 3 группы, экран шириной 390
- **THEN** в строке первая по алфавиту группа и «+2»

#### Scenario: Групп не больше, чем помещается
- **WHEN** у контакта 2 группы, экран широкий
- **THEN** видны обе группы, значка «+N» нет

#### Scenario: Без групп
- **WHEN** у контакта нет групп
- **THEN** в строке нет ни групп, ни значка, остальные данные на прежних местах

#### Scenario: Длинное имя группы
- **WHEN** у контакта группа с именем из 50 символов
- **THEN** имя группы обрезано с многоточием, имя контакта и «Кто это» видны целиком, как без группы

### Requirement: Всплывашка «+N»
Наведение мыши на «+N» и нажатие (тап) на него MUST показывать небольшую всплывашку со списком не показанных групп. Нажатие на «+N» MUST NOT открывать карточку контакта. Всплывашка MUST открываться с клавиатуры, закрываться по Escape и нажатием вне неё, а её содержимое MUST быть доступно скринридеру.

#### Scenario: Наведение
- **WHEN** у контакта 5 групп, на широком экране владелец наводит мышь на «+2»
- **THEN** всплывашка показывает две оставшиеся группы списком

#### Scenario: Тап на телефоне
- **WHEN** на экране 390 владелец нажимает «+2»
- **THEN** открывается всплывашка с остальными группами, карточка контакта не открывается

#### Scenario: Закрытие
- **WHEN** всплывашка открыта, и владелец нажимает Escape или вне неё
- **THEN** всплывашка закрывается

#### Scenario: С клавиатуры
- **WHEN** владелец переходит Tab на «+2» и нажимает Enter
- **THEN** всплывашка открывается, скринридер читает имена групп

### Requirement: Фильтр списка по группе
На главной MUST быть фильтр по одной группе. С фильтром список, счётчик и страницы MUST учитывать только контакты этой группы. Фильтр MUST сочетаться с поиском по имени и работать без JavaScript. Вид и место фильтра определяет эскиз.

#### Scenario: Список группы
- **WHEN** владелец выбирает фильтр «Теннис», в группе 7 контактов
- **THEN** в списке только эти 7 контактов, вверху «Найдено: 7»

#### Scenario: Фильтр и поиск вместе
- **WHEN** выбран фильтр «Теннис», и владелец ищет «Анна»
- **THEN** в списке только контакты группы «Теннис», в имени которых есть «Анна»

#### Scenario: Пустая группа
- **WHEN** владелец выбирает группу без контактов
- **THEN** пустое состояние «В группе пока никого нет»

#### Scenario: Сброс фильтра
- **WHEN** выбран фильтр, поиска нет, и владелец выбирает «Все группы»
- **THEN** список снова показывает всех контактов

#### Scenario: Сброс фильтра при поиске
- **WHEN** выбран фильтр «Теннис», задан поиск «Анна», и владелец выбирает «Все группы»
- **THEN** поиск «Анна» остаётся, в списке все контакты с «Анна» в имени из всех групп

#### Scenario: Сброс поиска внутри группы
- **WHEN** выбран фильтр «Теннис», задан поиск «Анна», и владелец нажимает «Сбросить» у поиска
- **THEN** фильтр «Теннис» остаётся, в списке все контакты группы

#### Scenario: Страницы с фильтром
- **WHEN** в группе 60 контактов, и владелец переходит на страницу 2
- **THEN** на странице 2 остальные контакты группы, фильтр не сброшен

#### Scenario: Группа удалена, а ссылка с фильтром осталась
- **WHEN** владелец открывает главную со ссылкой на фильтр по удалённой группе
- **THEN** список показывает всех контактов, как без фильтра

### Requirement: Переключатель «Контакты» и «Группы»
Над блоком «Пора связаться» на главной и вверху страницы «Группы» MUST быть переключатель «Контакты» / «Группы»; текущая страница MUST быть отмечена и доступна скринридеру как текущая.

#### Scenario: С главной на «Группы»
- **WHEN** владелец на главной нажимает «Группы» в переключателе
- **THEN** открывается страница «Группы», в переключателе отмечены «Группы»

#### Scenario: Обратно к контактам
- **WHEN** владелец на странице «Группы» нажимает «Контакты»
- **THEN** открывается главная без фильтра, в переключателе отмечены «Контакты»

### Requirement: Страница «Группы»
Страница «Группы» MUST показывать все группы по алфавиту с числом контактов в каждой; группа MUST вести на главную с фильтром по ней. На странице создают, переименовывают и удаляют группы; состав группы меняется в контакте.

#### Scenario: Список групп
- **WHEN** есть группы «Теннис» (7 контактов) и «Семья» (4 контакта)
- **THEN** на странице «Семья · 4» и «Теннис · 7» в этом порядке, каждая ведёт на главную с фильтром

#### Scenario: Число контактов меняется
- **WHEN** владелец добавляет контакт в «Семью»
- **THEN** на странице «Группы» у «Семьи» число контактов на 1 больше

### Requirement: Блок «Пора связаться» в группе
С фильтром по группе блок «Пора связаться» MUST показывать только контакты этой группы, в том же порядке и с теми же правилами раскрытия. Пустые состояния считаются по группе; для группы без контактов блок MUST NOT показываться.

#### Scenario: Блок в группе
- **WHEN** в группе «Теннис» просрочены 2 контакта, а всего просрочено 10
- **THEN** при фильтре «Теннис» в блоке только эти 2 контакта

#### Scenario: В группе все на связи
- **WHEN** у контактов группы есть частота, но никто не просрочен и не скоро, а в других группах просроченные есть
- **THEN** при фильтре по этой группе блок показывает «Со всеми на связи»

#### Scenario: Пустая группа без блока
- **WHEN** владелец выбирает группу без контактов
- **THEN** блока «Пора связаться» нет
