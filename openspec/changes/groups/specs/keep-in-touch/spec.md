# Spec Delta

## MODIFIED Requirements

### Requirement: Блок «Пора связаться»
На главной над списком контактов MUST быть блок «Пора связаться». Сначала - просроченные, по убыванию дней сверх срока; ниже - со статусом «скоро», по возрастанию дней до срока. При равенстве - по имени. Блок MUST показываться на первой странице списка без поиска, в том числе с фильтром по группе и на странице группы (тогда - только контакты группы), и MUST NOT показываться при поиске и на других страницах.

#### Scenario: Порядок просроченных
- **WHEN** у Анны «Раз в неделю» и прошло 20 дней с общения (13 сверх срока), а у Бориса «Раз в месяц» и срок прошёл 10 дней назад
- **THEN** Анна в блоке выше Бориса

#### Scenario: Скоро ниже просроченных
- **WHEN** у одного контакта срок прошёл вчера, у другого срок завтра
- **THEN** первый - в верхней части блока, второй - ниже

#### Scenario: Поиск
- **WHEN** владелец ищет контакт по имени
- **THEN** блока «Пора связаться» на странице нет

#### Scenario: Поиск внутри группы
- **WHEN** выбран фильтр по группе или открыта страница группы, и владелец ищет контакт по имени
- **THEN** блока «Пора связаться» на странице нет
