Группы контактов

Владелец сам заводит группы («Семья», «Теннис», «Аналитики») и раскладывает по ним людей. На главной можно сузить общий список до одной группы, у каждой группы есть своя страница, а на странице «Группы» ими управляют.

1Коротко

  • Группа — это набор контактов с названием. Готовых групп нет: все создаёт владелец.
  • Контакт может быть в нескольких группах или ни в одной.
  • Группы задаются в форме контакта, в карточке и на странице «Группы».
  • К людям одной группы два входа: фильтр на главной (сужает общий список) и новое — отдельная страница группы, где работают только с ней (решение 30).
  • Статус: сделана. Отмечены все 19 задач, все экраны проверены в браузере. Полный прогон (база, сборка, старые тесты в браузере) зелёный. Работа сохранена в ветке groups, но ещё не отправлена на GitHub и не выкачена: следующий шаг — ваше «коммить и пуш», PR, выкатка, проверка на проде.
  • Чем покрыт каждый сценарий — в coverage.md рядом с этой страницей. Автотесты (программы, которые сами проходят сценарий и сверяют результат) есть у 53 сценариев. 13 проверены только руками в браузере: их предлагается перенести в тесты в настоящем браузере (e2e), которые пишутся отдельной вашей командой.

3Как это работает

Название группы: обязательно, до 50 символов, без повторов

Пробелы по краям отрезаются. Повтором считается то же название в другом регистре или с «е» вместо «ё».

Есть «Друзья» → «друзья» нельзя: «Такая группа уже есть».
Есть «Ёлка» → «Елка» нельзя.
Пусто → «Укажи название». 51 символ → «Не длиннее 50 символов».
Переименование не меняет состав

Можно сменить только регистр — это не ошибка. Если группу тем временем удалили в другой вкладке — ничего не сохраняется, ошибка «Группа не найдена», введённое имя остаётся.

«теннис» → «Теннис»: сохраняется. «Теннис» → «Теннис по субботам»: те же 7 человек, в карточках новое название.
Удаление группы не удаляет людей

Только после подтверждения. Пропадает только членство в этой группе. Данные, заметки и другие группы контактов — на месте. Удаление контакта убирает его из всех групп.

В «Аналитиках» 3 человека. Удаляю группу → 3 человека остались, у Анны по-прежнему «Друзья» и «Теннис».
Форма возвращает туда, откуда её открыли

«Добавить контакт» со страницы группы — в форме уже отмечена эта группа, «Отмена» и «Все контакты» ведут обратно на страницу группы. С главной — на главную.

Страница «Теннис» → «Добавить контакт» → передумала, «Отмена» → снова страница «Теннис».
Группа в контакте: найти или создать

Так работают поле «Новая группа» в форме и поле «Группа: выбрать или новая» в карточке. Такая группа уже есть — ошибки нет, контакт просто попадает в неё. На странице «Группы» то же название — ошибка: там цель именно новая группа.

Есть «Друзья». В форме или карточке пишу «друзья» → контакт в «Друзьях», вторая группа не появилась.
Убрать из группы — только после подтверждения

Крестик у группы в карточке открывает вопрос «Убрать из группы «…»?». «Отмена» ничего не меняет. Сама группа не удаляется.

Анна в «Друзьях» и «Теннисе». Крестик у «Теннис» → «Убрать» → у Анны только «Друзья», «Теннис» на странице «Группы» остался.
Два входа к людям группы — для разных задач

Фильтр на главной сужает общий список и оставляет на главной. Страница группы — работа только с одной группой: свой заголовок, поиск внутри группы, «Добавить контакт» сразу в группу.

Нужно найти Анну среди теннисистов, не уходя из общего списка → фильтр на главной.
Разбираю группу «Теннис» → «Группы» → «Теннис» → страница группы.
Сколько групп видно в строке списка

Группы по алфавиту. Больше 1100px — три, 681–1100px — одна во всю колонку, до 680px (телефон) — одна, отдельной строкой. Остальные — «+N», где N — сколько не показано.

5 групп: компьютер → 3 и «+2»; узкое окно, планшет или телефон → 1 и «+4».
2 группы на компьютере → обе, без «+N».
Всплывашка «+N»

Открывается наведением мыши, нажатием, тапом или с клавиатуры (Tab, затем Enter). Появляется под «+N», заголовок — «Ещё N групп». Закрывается по Escape, нажатием вне неё или при прокрутке. Скринридер (программа, которая читает экран вслух) читает названия групп. Открытие по нажатию работает и без JavaScript.

Фильтр на главной

Список, «Найдено: N» и страницы считают только людей группы. Поиск и фильтр — одна форма: группа применяется сразу при выборе, без JavaScript — кнопкой «Найти». «Все группы» снимает фильтр, поиск остаётся. «Сбросить» убирает только поиск, группа остаётся.

«Теннис» + поиск «Анна» → «Все группы» → все Анны из всех групп.
«Теннис» + поиск «Анна» → «Сбросить» → все из «Тенниса».

Пока групп нет, фильтра нет: с одним вариантом «Все группы» он бесполезен. Вместо него — ссылка «Тут можно создавать группы контактов».

Удалённая группа в старой ссылке

На главной фильтр по ней просто не применяется — видны все контакты. Страница группы показывает «Не найдено».

«Пора связаться» по группе

С фильтром на главной и на странице группы — те же правила и порядок, но только люди группы. При поиске блока нет. Группа без людей — блока нет.

Всего просрочено 10, из них в «Теннисе» 2 → в блоке 2.
В группе никто не просрочен, а в других есть → «Со всеми на связи».
Переключатель «Контакты» / «Группы»

Под заголовком на главной и на странице «Группы». Текущая страница отмечена. «Контакты» всегда ведут на главную без фильтра. На странице группы переключателя нет.

Всё работает без JavaScript

Формы, фильтр, страница группы, подтверждения и открытие «+N» по нажатию. Без JavaScript не будет только открытия всплывашки по наведению мыши.

Миграция

Миграция — скрипт, который меняет устройство базы. Она одна и уже написана: drizzle/0002_gorgeous_magdalene.sql. На сервер попадёт при выкатке.

  1. Таблица groups данные не меняет

    С правилами: название обязательно, не длиннее 50 символов, без повторов с учётом «е/ё» и регистра.

  2. Таблица contact_groups данные не меняет

    Связи с контактами и группами; указатель, чтобы фильтр по группе работал быстро.

  • Что с уже существующими контактами: все остаются без групп. Имена, частота, заметки — на месте. Групп после выкатки нет, пока вы их не создадите.
  • Проверка миграции — автотест. Он создаёт временную базу, кладёт в неё выдуманные контакты и заметки, применяет миграцию и сверяет каждую старую строку. Результат: старые данные не изменились, новые таблицы пустые. Рабочую базу тест не трогает.

Как откатиться

Прошлая версия приложения новые таблицы просто не читает и работает как раньше. Базу откатывать не нужно. Созданные группы сохранятся в базе и вернутся при повторной выкатке.

Подготовка. Запустите приложение локально (pnpm dev, см. README). Демо-данные (сид) уже содержат 6–8 выдуманных групп, одну с названием на 50 символов, и контакты с 0, 1, 2 и 5 группами. Все сценарии можно пройти уже сейчас. Агент прошёл их в браузере при реализации; ниже — для вашей приёмки. Метки: «автотест есть» — сценарий проверяет и программа (файлы и строки — в coverage.md); «руками» — только ручная проверка, автотеста нет. Продуктовые — стоит просмотреть

Вид и поведение фильтра, групп в карточке и строках, подтверждения, страница группы, ссылка при пустом списке групп и возврат из формы выбраны вами (design/README.md, решения 21–31; 404 для удалённой группы — тоже ваш выбор). Ниже — то, что в документах не отмечено как ваше решение.

  • Текст диалога удаления группы: «N контактов останутся, только без этой группы.», для пустой — «В группе пока никого нет.».
  • «Отмена» в диалогах подтверждения — кнопка с рамкой, как при удалении контакта; в эскизе — без рамки.
  • Принято как есть: после закрытия диалога фокус клавиатуры уходит в начало страницы; текст «останется в остальных группах» пишется, даже если группа у контакта одна.
  • Название существующей группы в контакте (форма или карточка) — не ошибка, контакт попадает в неё. На странице «Группы» — ошибка.
  • В форме — одна новая группа за одно сохранение.
  • Состав группы меняется только в контакте; на странице «Группы» — только создать, переименовать, удалить.
  • На главной ссылка на удалённую группу показывает все контакты, а не «Не найдено».
  • «Контакты» в переключателе всегда сбрасывают фильтр.
  • Подсказки в поле карточки — только группы, где контакта ещё нет.
  • Всплывашка по наведению открывается с задержкой (~0,15 с) и закрывается при прокрутке.
  • Вне фичи: фильтр по нескольким группам, вложенные группы, цвета и иконки, массовое добавление людей в группу.

Технические — на экраны не влияют

  • Две таблицы со связью «многие ко многим», а не список групп внутри контакта: база сама чистит связи при удалении.
  • Повтор названия ловит база, а не только форма — так не пройдёт дубль из двух вкладок одновременно.
  • Контакт и его группы сохраняются одним действием: ошибка в любом поле — не записывается ничего.
  • Сколько групп видно в строке, решает разметка, а не скрипт: без мигания при загрузке и без JavaScript. Значки «+N» выводятся для всех трёх ширин, лишние прячутся.
  • Всплывашка — встроенная возможность браузера (popover), новых библиотек нет. Место под «+N» считает маленький скрипт.
  • Строку списка перестраивают, чтобы «+N» был кнопкой поверх ссылки на карточку — как «Связались» в блоке.
  • Подтверждения без JavaScript — отдельный адрес страницы с открытым диалогом; с JavaScript — тот же диалог без перехода. Один общий компонент для всех подтверждений.
  • Фильтр хранится в адресе страницы (?group=…), как поиск и номер страницы.
  • Главная и страница группы берут данные одними и теми же запросами и рисуют строки одним общим куском разметки.
  • Список групп сортируется так же, как сравниваются названия: «ё» как «е», без учёта регистра.
  • Отметки групп, удалённых в другой вкладке, при сохранении контакта отбрасываются.
  • В логах — только код ошибки, без названий групп. Каждая новая миграция обязана иметь свой автотест на старых данных.

7Что осталось неясным

Текст диалога «Удалить группу?».

В требованиях и эскизе нет текста для группы без людей. В коде сейчас «В группе пока никого нет.», для остальных — «N контактов останутся, только без этой группы.». Подходит?

«Отмена» в диалоге: с рамкой или без.

Решение 12 и эскиз — без рамки (ghost). В коде — с рамкой, как в уже сделанном «Удалить контакт?». Оставить как в коде или привести оба диалога к эскизу?

Когда писать e2e на 13 ручных сценариев.

Переключатель, всплывашка «+N» (наведение, закрытие, клавиатура), отмены в диалогах, переходы со страницы группы, «Групп нет», блок при пустой группе и при поиске в группе сейчас проверены только руками. По плану e2e пишутся вашей отдельной командой — до выкатки или после, решать вам.
