Группы контактов

Владелец сам заводит группы («Семья», «Теннис», «Аналитики») и раскладывает по ним людей. На главной можно показать только одну группу, а на отдельной странице — управлять группами.

1Коротко

  • Группа — это набор контактов с названием. Готовых групп нет: все создаёт владелец.
  • Контакт может быть в нескольких группах или ни в одной.
  • Группы задаются в форме контакта, в карточке и на новой странице «Группы».
  • На главной — фильтр по одной группе. Работает вместе с поиском и с блоком «Пора связаться».
  • Статус: спроектирована. Отмечена 1 задача из 18 — эскизы экранов (design/). Задача 1.2 «владелец утвердил эскизы» ещё не отмечена. Кода нет.
  • По эскизам вы выбрали вид фильтра (список в строке поиска) и групп в карточке (плашки с крестиком). Подтверждение «Убрать из группы?» в design/README.md пока «предложено».
  • Автотесты (программы, которые сами проходят сценарий и сверяют результат) запланированы для 31 сценария. Ещё 18 — проверка руками в браузере. Тесты в настоящем браузере (e2e) для этой фичи отложены в specs/backlog.md.

2Что появится на экранах

Наброски по утверждённым эскизам в design/ (смотреть: design/index.html). Точный вид — там. Новое обведено пунктиром. Имена и числа выдуманы.

3Как это работает

Название группы: обязательно, до 50 символов, без повторов

Пробелы по краям отрезаются. Повтором считается то же название в другом регистре или с «е» вместо «ё».

Есть «Друзья» → «друзья» нельзя: «Такая группа уже есть».
Есть «Ёлка» → «Елка» нельзя.
Пусто → «Укажи название». 51 символ → «Не длиннее 50 символов».
Группа в контакте: найти или создать

Так работают поле «Новая группа» в форме и поле «Группа: выбрать или новая» в карточке. Если такая группа уже есть, ошибки нет — контакт просто попадает в неё. На странице «Группы» то же название — ошибка: там цель именно новая группа.

Есть «Друзья». В форме или карточке пишу «друзья» → контакт в «Друзьях», вторая группа не появилась.
Убрать из группы — только после подтверждения

Крестик у группы в карточке открывает вопрос «Убрать из группы «…»?». «Отмена» ничего не меняет. Сама группа не удаляется.

Анна в «Друзьях» и «Теннисе». Крестик у «Теннис» → «Убрать» → у Анны только «Друзья», «Теннис» на странице «Группы» остался.
Переименование не меняет состав

Можно сменить только регистр — это не ошибка.

«теннис» → «Теннис»: сохраняется. «Теннис» → «Теннис по субботам»: те же 7 человек, в карточках новое название.
Удаление группы не удаляет людей

Пропадает только членство в этой группе. Данные, заметки и другие группы контактов — на месте. Удаление контакта убирает его из всех групп.

В «Аналитиках» 3 человека. Удаляю группу → 3 человека остались, у Анны по-прежнему «Друзья» и «Теннис».
Сколько групп видно в строке списка

Группы по алфавиту. Сколько видно, решает ширина экрана: больше 1100px — три, 681–1100px — две, до 680px (телефон) — одна, отдельной строкой. Остальные — «+N», где N — сколько не показано.

5 групп: компьютер → 3 группы и «+2»; узкое окно или планшет → 2 и «+3»; телефон → 1 и «+4».
2 группы на компьютере → обе, без «+N».
Всплывашка «+N»

Открывается наведением мыши, нажатием, тапом или с клавиатуры (Tab, затем Enter). Появляется под «+N», заголовок — «Ещё N групп». Закрывается по Escape, нажатием вне неё или при прокрутке страницы. Нажатие после наведения её не закрывает. Скринридер (программа, которая читает экран вслух) читает названия групп. Открытие по нажатию работает и без JavaScript.

Фильтр по одной группе

Список, счётчик «Найдено: N» и страницы считают только людей группы. Фильтр сочетается с поиском и сохраняется при переходе по страницам. Фильтр хранится в адресе страницы, поэтому ссылку можно сохранить.

Группа применяется сразу при выборе. Без JavaScript — кнопкой «Найти». «Сбросить» убирает и группу, и поиск.

«Теннис», 7 человек → «Найдено: 7». «Теннис» + поиск «Анна» → только Анны из «Тенниса».
Ссылка на удалённую группу → показываются все контакты, как без фильтра.
«Пора связаться» с фильтром

Те же правила и порядок, но только люди группы. При поиске блока нет — как и без фильтра. Группа без людей — блока нет.

Всего просрочено 10, из них в «Теннисе» 2 → с фильтром «Теннис» в блоке 2.
В группе никто не просрочен, а в других есть → в блоке «Со всеми на связи».
Переключатель «Контакты» / «Группы»

Стоит над блоком «Пора связаться» на главной и вверху страницы «Группы». Текущая страница отмечена. «Контакты» всегда ведут на главную без фильтра.

Всё работает без JavaScript

Формы, фильтр, группы в карточке с подтверждением и открытие «+N» по нажатию — как остальные формы приложения. Без JavaScript не будет только открытия по наведению мыши.

Модель данных — какие таблицы лежат в базе и какие в них поля. Фича добавляет две новые таблицы. Старые таблицы не меняются.

Схему можно листать вбок.

  • groups — сами группы: название и когда создана. Повтор названия (без учёта регистра и «е/ё») и длину больше 50 не пропустит сама база, а не только форма.
  • contact_groups — кто в какой группе. Одна строка — одна пара «контакт + группа», одна и та же пара дважды не запишется.
  • Удалили контакт — его строки в contact_groups удаляются сами. Удалили группу — удаляются её строки, сами контакты не трогаются.

Миграция

Миграция — скрипт, который меняет устройство базы. Она одна, создаётся командой Drizzle из описания таблиц в коде.

  1. Таблица groups данные не меняет

    С правилами: название обязательно, не длиннее 50 символов, без повторов с учётом «е/ё» и регистра.

  2. Таблица contact_groups данные не меняет

    Связи с контактами и группами; указатель, чтобы фильтр по группе работал быстро.

  • Что с уже существующими контактами: все остаются без групп. Имена, частота, заметки — на месте. Групп после выкатки нет, пока вы их не создадите.
  • Проверка миграции: задача 4.3 — сравнить данные до и после на временной или демо-базе.

Как откатиться

Прошлая версия приложения новые таблицы просто не читает и работает как раньше. Базу откатывать не нужно. Созданные группы при этом сохранятся в базе и вернутся при повторной выкатке.

5Как проверить руками

Подготовка. Проверять можно, когда фича будет сделана. Запустите приложение локально (pnpm dev, см. README). Демо-данные (сид) будут содержать 6–8 выдуманных групп, одну с названием на 50 символов, и контакты с 0, 1, 2 и 5 группами. Метка «автотест в плане» — сценарий проверит программа; «руками» — автотеста для него в плане нет. Галочки на этой странице только для удобства и не сохраняются.

6Что агент решил сам

Продуктовые — стоит просмотреть

Вид фильтра, групп в карточке и строк выбран вами по эскизам (design/README.md, решения 21–27). Ниже — то, что в документах не отмечено как ваше решение.

  • Название существующей группы в контакте (форма или карточка) — не ошибка, контакт попадает в неё. На странице «Группы» — ошибка.
  • В форме — одна новая группа за одно сохранение.
  • Состав группы меняется только в контакте; на странице «Группы» — только создать, переименовать, удалить.
  • Ссылка на удалённую группу показывает все контакты, а не ошибку «не найдено».
  • «Контакты» в переключателе всегда сбрасывают фильтр.
  • «Сбросить» в строке поиска убирает сразу и группу, и поиск.
  • Подсказки в поле карточки — только группы, где контакта ещё нет.
  • Всплывашка по наведению открывается с небольшой задержкой (~0,15 с) и закрывается при прокрутке страницы.
  • Вне фичи: фильтр по нескольким группам, вложенные группы, цвета и иконки, массовое добавление людей в группу.

Технические — на экраны не влияют

  • Две таблицы со связью «многие ко многим», а не список групп внутри контакта: база сама чистит связи при удалении.
  • Повтор названия ловит база, а не только форма — так не пройдёт дубль из двух вкладок одновременно.
  • Контакт и его группы сохраняются одним действием: ошибка в любом поле — не записывается ничего.
  • Сколько групп видно в строке, решает разметка страницы, а не скрипт: без мигания при загрузке и без JavaScript.
  • Всплывашка — встроенная возможность браузера (popover), новых библиотек нет.
  • Строку списка перестраивают, чтобы «+N» был кнопкой поверх ссылки на карточку — как «Связались» в блоке.
  • Место всплывашки под «+N» считает маленький скрипт: нужная возможность CSS есть не во всех браузерах.
  • Подтверждение «Убрать из группы» без JavaScript — отдельный адрес карточки с открытым диалогом; с JavaScript — тот же диалог без перехода.
  • Фильтр хранится в адресе страницы (?group=…), как поиск и номер страницы.
  • В логах — только код ошибки, без названий групп.
  • Тесты в настоящем браузере (e2e) для фичи и их подключение к CI отложены в backlog.
