- Личная CRM: контакты людей, которых владелец знает лично
- Идея, главный сценарий, ограничения - `specs/01-продуктовая-идея.md`

- Дизайн экранов: статус, решения, план переноса в код - `design/README.md`; исходная дизайн-система - `ak-design-system/` (не в git)

## Язык кода

- Код и всё, что к нему относится, - на английском: имена файлов, переменных, функций, таблиц и полей, комментарии, тексты ошибок и логов, коммиты, ветки, PR
- На русском - только тексты интерфейса, которые видит пользователь, и README.md

## Стек

- Next.js (App Router), TypeScript
- React, Tailwind CSS, shadcn/ui; цвета, шрифты и отступы - только через дизайн-токены
- PostgreSQL, Drizzle: схема и миграции в коде
- pnpm, `pnpm-lock.yaml` в git
- Docker: локально только Postgres, образ приложения собирает CI
- GitHub Actions, образы в GHCR
- VPS, docker compose, nginx, certbot
- Версии GitHub Actions и библиотек - последние стабильные: проверяй актуальные, не бери по памяти

## Секреты и данные

- Пароли, ключи, строки подключения - только в `.env`; в git - `.env.example` без значений; `.env` в `.gitignore`
- `.env`: не читать и не писать, сказать, какую строку добавить
- `.env` на сервере - права 600: читает только владелец
- Ключ деплоя в GitHub создаёшь и кладёшь сам через gh: сам ключ не выводи
- Перед коммитом - проверка на секреты (например, gitleaks)
- Репо публичное: тестовые данные только выдуманные, никаких реальных людей в коде, фикстурах, сидах и скриншотах

## Выкатка

### Окружения и сервер

- На сервере docker compose, проект `prod` (`-p prod`)
- Сервер общий для приложения и лендинга: чужие ключи, папки и настройки nginx на нём не удаляй и не меняй - только добавляй своё; удалить - только с согласия владельца
- Диск сервера не забивается: после удачной выкатки оставляй только текущий и предыдущий образы, логи контейнеров ограничь по размеру

### Как выкатываем

- Скрипты выкатки - в `deploy/` в репо, выкатка копирует их на сервер; в workflow только их вызов
- Push в main → образ с тегом SHA коммита → GHCR → на сервере: миграции → новый образ → smoke `/health`
- Миграции - отдельный шаг до старта нового образа: разовый контейнер из того же образа применяет миграции и завершается; упали миграции - новый образ не стартует
- После выкатки скажи, как проверить

### Сбой и откат

- Красный smoke - выкатка упала, сообщи владельцу. Сам ничего не откатывай, автооткат в скрипты не ставь: откат только вручную, запускает владелец
